# 股票量化交易可视化系统

## 项目简介

基于Python的股票交易数据可视化系统，支持K线图展示、技术指标分析和交易策略模拟。

## 功能特性

- **数据爬取**: 使用Tushare API获取实时股票数据
- **K线图可视化**: 双Y轴显示价格和成交量
- **技术指标**: 5日、10日、20日移动平均线
- **交易策略**: 均线策略、突破策略
- **数据表格**: 显示最近30天详细交易数据
- **交易日志**: 记录策略执行结果

## 安装说明

### 1. 安装Python环境

确保已安装Python 3.7或更高版本。

### 2. 安装依赖包

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install pandas matplotlib tushare pillow
```

### 3. 获取Tushare Token（可选）

访问 [https://tushare.pro](https://tushare.pro) 注册并获取免费token。

## 使用方法

### 方法一：直接运行主程序

```bash
python main.py
```

程序会自动加载`raw`目录或当前目录中的CSV文件。

### 方法二：先爬取数据再运行

1. 运行数据爬取工具：

```bash
python data_scraper.py
```

2. 按提示输入Tushare token（可选）

3. 选择爬取模式：
   - 单只股票
   - 100只热门股票
   - 自定义股票列表

4. 等待数据爬取完成（保存在`data`目录）

5. 运行主程序：

```bash
python main.py
```

## 数据格式

CSV文件格式示例：

```csv
ts_code,trade_date,open,high,low,close,pre_close,change,pct_chg,vol,amount
000066.SZ,20220701,10.8,11.06,10.75,10.76,10.82,-0.06,-0.5545,302277.17,329502.961
```

必需字段：
- `trade_date`: 交易日期 (YYYYMMDD)
- `open`: 开盘价
- `high`: 最高价
- `low`: 最低价
- `close`: 收盘价
- `vol`: 成交量

## 交易策略说明

### 均线策略

基于移动平均线的金叉死叉判断：
- **金叉（买入）**: MA5上穿MA10
- **死叉（卖出）**: MA5下穿MA10

### 突破策略

基于价格突破判断：
- **买入信号**: 接近20日最高价
- **卖出信号**: 接近20日最低价

pyinstaller --onefile --windowed --name="股票分析系统" main.py

## 注意事项

1. **API限制**: Tushare免费token有调用频率限制，建议批量爬取时设置适当延迟
2. **数据时效**: 股票数据需定期更新
3. **中文字体**: 如图表中文显示异常，需安装中文字体（SimHei或Microsoft YaHei）
4. **策略仅供参考**: 本系统的交易策略仅用于学习演示，不构成投资建议

## 常见问题

### Q: 图表中文显示为方框？
A: 需要安装中文字体。macOS可使用Arial Unicode MS，Windows使用SimHei或Microsoft YaHei。

### Q: 无法连接Tushare API？
A: 检查网络连接，或使用本地CSV数据文件。

### Q: 数据爬取失败？
A: 确认token有效性，或降低爬取频率（增加delay参数）。
